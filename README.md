# Ketan's 100 Days — Ravneet's Run

Static web app generated from Ravneet's curated 100-day plan (source: @ketan_lifts7's
Mar 5 – Aug 19, 2024 "entering the gym from scratch" series).

- `index.html` — overview, rules, food/supplements, all 100 day cards, teaching extras.
- `day-001.html` … `day-100.html` — one self-contained page per programme day:
  session, warm-up, no-failure stop metrics, per-exercise log (saved in the browser's
  localStorage), Ketan's principle, and his original reel.
- Schedule: Day 1 Mon Oct 19, 2026 → Day 100 Tue Mar 23, 2027 (Mon–Fri programme days,
  full pause Nov 19 – Dec 4, 2026 for Australia).
- Generated by `~/workspace/ketan-100day/build_app.py` from the plan data files.
